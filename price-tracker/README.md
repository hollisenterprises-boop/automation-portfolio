# Competitor price tracker

Checking competitors' prices by hand is slow, and it is easy to miss a price cut or a product coming back into stock. This tool does the checking for you. Each run it reads a competitor's online catalogue, saves a dated copy of every product's price and stock, compares it with the last run and writes an Excel report of what changed.

## What the report shows

`output/price_report.xlsx` has six sheets:

- **Summary**: products tracked, average price, price drops and rises, new and gone products, stock changes, and the biggest price moves as a table and a chart.
- **Price changes**: every product whose price moved, with the old and new price and the change in £ and %, biggest drops first.
- **New products**: products listed now that were not there last time.
- **Gone**: products that were listed last time but have disappeared.
- **Stock changes**: products that came back into stock or sold out.
- **All products**: the full list from this run, with price, star rating, stock and a link to each product page.

Each run also saves its data as a dated CSV in `snapshots/` (for example `2026-10-18_1641.csv`), so a price history builds up that you can open in Excel.

## How to run it

With Python 3 installed (tested on 3.12):

```
pip install pandas openpyxl requests beautifulsoup4
python price_tracker.py
```

The second command visits the site (5 pages, 100 products, at most one page a second), saves a snapshot and writes the report. `python price_tracker.py --compare-only` rebuilds the report from the saved snapshots without visiting the site. `python price_tracker.py --help` lists the other options (`--pages`, `--delay`, `--snapshots`, `-o`).

## How often

Once a day suits most sellers. Windows Task Scheduler can run it every morning: create a basic task, choose "Start a program", give the path to `python.exe` as the program and the full path to `price_tracker.py` as the argument. Keep `--pages` the same on every run so each comparison is like for like.

## About this demo

The demo reads [books.toscrape.com](https://books.toscrape.com/), a practice shop built for people learning web scraping, so no real business is involved. The newest snapshot (18 Oct 2026) is a real run.

That site's prices never change, so the earlier snapshot (11 Oct 2026) is **generated, not real**. `make_demo_history.py` copied the real run and moved 12 prices by 5-25%, left out 4 products (they show as new) and marked 2 as out of stock (they show as back in stock), so the report has changes to show. The report says this under its title. To rebuild the demo:

```
python price_tracker.py
python make_demo_history.py
python price_tracker.py --compare-only --note "Demo: the earlier snapshot was generated by make_demo_history.py, because the practice site's prices never change."
```

Tests, no internet needed: `python -m pytest tests`

## For your shop

The same tracker can watch your real competitors' sites. Each site gets its own small page reader, every run respects the site's terms and robots.txt, and an email alert can be added for when a competitor changes a price.
